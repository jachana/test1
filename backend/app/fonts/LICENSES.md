# Bundled Font Licences

All fonts here permit embedding, outlining (text-to-path), and commercial use.

## Great Vibes (`GreatVibes-Regular.ttf`)
- **Role:** `script-default` — script style for names.
- **Author:** TypeSETit / the Great Vibes Project Authors.
- **Licence:** SIL Open Font License 1.1 (OFL). Permits use, embedding,
  modification, and commercial output. https://openfontlicense.org

## DejaVu Sans (`DejaVuSans.ttf`)
- **Role:** `sans-default` — clean sans-serif for details.
- **Licence:** DejaVu Fonts Licence (a permissive Bitstream Vera derivative).
  Free for any use including embedding and commercial work.

## DejaVu Serif (`DejaVuSerif.ttf`)
- **Role:** `serif-default` — serif for headlines.
- **Licence:** DejaVu Fonts Licence (Bitstream Vera derivative). Permissive.

Users may only select these bundled fonts by key; arbitrary font file paths are
never accepted from requests (see security notes in `docs/architecture.md`).
